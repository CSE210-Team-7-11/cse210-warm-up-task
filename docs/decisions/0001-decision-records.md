# ADR-0001: Record decisions with lightweight MADR

## Decision Outcome

Each record states the decision, the rationale, and the alternatives
considered. Records stay lightweight, to set the repository standard without
adding bureaucracy.

### Consequences

- Bad: records add some writing overhead.
- Leads write the initial records. Later records come from the discussion that leads to each decision.
